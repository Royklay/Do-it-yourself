# DoItYourself 

## About the Project

DoItYourself is a simple DIY repair guide website that helps users understand and solve common problems with everyday devices and equipment.

The goal of the project is to help people handle minor repairs themselves instead of spending money on problems they can fix at home.

The website provides simple explanations and step-by-step instructions for common problems.

## Live Website

**Live Link:**  https://royklay.github.io/Do-it-yourself/

## Features

- Browse different repair categories.
- Search for repair categories.
- Read simple step-by-step repair guides.
- Interactive 3D car engine model with problem highlighting.
- Sign In and Get Started pages.
- About and Help pages.

## Repair Categories

- Cars

- Mouse
- Keyboard
- Printers
- Bicycles

## How to Set Up the Project

Follow these steps to run the project on your computer:

1. Download this repository.
2. Extract the project folder if it is downloaded as a ZIP file.
3. Open the project folder in Visual Studio Code.
4. Make sure the project files and folders are in their correct locations.
5. Open `index.html` in your browser.
